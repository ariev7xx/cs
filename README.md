## Tentang

**csAriev** adalah kumpulan plugin [CloudStream 3](https://github.com/recloudstream/cloudstream) untuk situs streaming populer di Indonesia. Plugin ini memungkinkan kamu menonton anime, film, dan drama langsung dari aplikasi CloudStream di Android.

### Fitur

- Streaming anime subtitle Indonesia
- Film dan drama Indonesia
- Support multiple server
- Download support
- Gratis dan open source

## Instalasi

### Prasyarat

- [CloudStream 3](https://github.com/recloudstream/cloudstream) terinstall di Android

### Cara Install

1. Buka CloudStream
2. Masuk ke **Settings** > **Repository**
3. Tambahkan kode pendek repository berikut:

```
ariev7
```

4. Kembali ke halaman utama, plugin akan muncul di tab **Extensions**
5. Install plugin yang diinginkan
